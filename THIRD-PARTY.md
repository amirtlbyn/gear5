# Third-party material

The MIT license in `LICENSE` covers the code written for this project. These parts
come from, or are based on, other people's work:

## summer-day-and-night by MathisP75
<https://github.com/MathisP75/summer-day-and-night>

This project started as that rice. The Everforest bar look (`config/waybar/*/style.css`,
`config/waybar/colors/`), the theme colors in `config/hypr/themes/` and the overall
design come from it. Its **wallpapers and kitty colors are not included here**: the
installer downloads them from the original repository. The original repository has
no license file, so its own files remain its author's.

## Unicode emoji data
`config/waybar/scripts/emoji-data.txt` is generated from Unicode's
[`emoji-test.txt`](https://unicode.org/Public/emoji/latest/emoji-test.txt) (Emoji 18.0)
and the CLDR English emoji annotations
([cldr-json](https://github.com/unicode-org/cldr-json)).

> Copyright © 1991-2026 Unicode, Inc. All rights reserved. Distributed under the
> Unicode License v3 (<https://www.unicode.org/license.txt>).

Extra search keywords come from the emoji list in
[wofi-emoji](https://github.com/Zeioth/wofi-emoji) (MIT).
